# AI answer check — short script

**Working title:** AI ka answer confident hai? 3 checks karo  
**Audience:** Hindi/Hinglish students and everyday AI users  
**Format:** vertical 9:16, 27 seconds, caption-led  
**Voiceover:** optional creator-recorded read; the MP4 is caption-led and does not include generated speech.

| Time | Voiceover / on-screen copy | Visual beat |
| --- | --- | --- |
| 0–4s | “AI ne confident answer diya? Ek second—pehle teen checks.” | Student pauses at an AI answer; magnifier appears. |
| 4–10s | “Pehla: original source kholo. Quote aur date, page par match karo.” | Open the source itself; compare claim and source page. |
| 10–16s | “Doosra: ek independent, reliable source se cross-check.” | Two separate reference cards sit side-by-side. |
| 16–22s | “Teesra: calculation ya code hai? Safe tareeke se khud test karo.” | Calculator/code panel resolves to a check mark. |
| 22–27s | “Proof na mile, toh answer ko fact mat bolo. Save karo—Learn with Avee.” | Three checks and save/bookmark end card. |

**Accuracy note:** the video teaches a verification habit. It does not assert a made-up statistic or name a specific AI tool as error-free.
